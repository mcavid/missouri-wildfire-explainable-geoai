# Publication and reviewer-access checklist

This package is prepared locally for the authors’ publication repository.
This checklist does not authorize changes
to visibility, publication of a GitHub release, or creation of a DOI.

1. Review the research files and MIT code license; confirm any separate derived
   data/model/figure permissions described in DATA_LICENSE.md with the authors.
2. Run verification and retain its report; the included GitHub Actions workflow can repeat the checks after upload.
3. Confirm that reviewers can access the repository URL; arrange access if
   the repository is private.
4. When ready, deliberately change visibility according to the authors' publication
   plan and verify the manuscript URL without an authenticated session.
5. Tag the approved paper version, create a release, and optionally archive it with
   a DOI service such as Zenodo. Add the genuine DOI to CITATION.cff after creation.
6. When the paper is published, replace the unpublished preferred citation with
   its actual article metadata. Do not guess a journal DOI, issue or date.
